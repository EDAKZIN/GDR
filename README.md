# GDR

![Tauri](https://img.shields.io/badge/Tauri-2-blue) ![React](https://img.shields.io/badge/React-19-61dafb) ![SQLite](https://img.shields.io/badge/SQLite-FTS5-003b57) ![License](https://img.shields.io/badge/Licencia-MIT-green)

Gestor de datos genérico de escritorio (Tauri 2 + React + SQLite): el usuario define
sus propias secciones, plantillas de formularios y campos para organizar registros.
Nada está hardcodeado: la estructura la decide el usuario en tiempo de ejecución.

Generic desktop data manager (Tauri 2 + React + SQLite): the user defines their own
sections, form templates and fields to organize records. Nothing is hardcoded:
the structure is decided by the user at runtime.
